Sonatype Security Research is monitoring a malicious npm campaign attributed to Lazarus Group that distributes dozens of compromised packages using brandjacking methods including suffix insertion, version imitation, and name embedding to appear legitimate. Analyzed packages like buffer-utilities function as dropper mechanisms that retrieve and execute remote code, establishing persistent attacker infrastructure in developer environments.
