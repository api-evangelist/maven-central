Sonatype Security Research is tracking a new malware campaign with 281 compromised npm package versions that exploits binding.gyp files to execute code during installation, bypassing traditional package.json script defenses. The malware collects developer data, steals credentials, and can self-propagate through stolen maintainer access, representing an escalation in supply chain attack sophistication.
